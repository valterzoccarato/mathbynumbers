# mathbynumbers

Portale di matematica interattiva — esplorazioni, pattern nascosti nei numeri e qualche gioco.

## Struttura

- `home.html` / `home_en.html` — home page con i riquadri di navigazione
- `fibonacci.html` / `fibonacci_en.html` — spirale di Fibonacci e sezione aurea
- `numeri-primi.html` / `numeri-primi_en.html` — numeri primi su reticolo quadrato (Ulam) e triangolare, con tab di selezione
- `decimali.html` / `decimali_en.html` — placeholder per la sezione sulla ricerca dei decimali di π, √2, e (da costruire)
- `gioco/` — Numeroids, il gioco arcade con asteroidi-numero
- `archive/` — versioni precedenti di ulam.html e triangolo.html, sostituite da numeri-primi.html; tenute solo per riferimento
